# Brand Instructions for Claude Code

Before any frontend/UI work:
- read `brand/BRAND.md`
- read `brand/design-tokens.json`
- reuse `src/brand.css`

Operating principle:
**Dark technical foundation. Pink energy. Human warmth.**

Rules:
1. Preserve usability before decoration.
2. Do not introduce generic SaaS blue as a primary color.
3. Pink is an accent, not a background.
4. Do not make every card glow.
5. Prefer spacing and hierarchy over card-heavy layouts.
6. Use semantic green/amber/blue/red for status.
7. Avoid generic robot/AI imagery.
8. Keep copy intelligent, warm and concrete.
9. Reuse existing components.
10. When in doubt: reduce decoration, not personality.

Before implementing a redesign, explain:
- what you will keep
- what you will change
- which brand tokens/components you will use
