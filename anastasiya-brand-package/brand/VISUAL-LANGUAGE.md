# Visual Language

## Mood
Modern tech + warm human workspace.

## Use
- near-black backgrounds
- neon pink as emphasis
- subtle purple support
- white/off-white text
- warm amber photographic highlights
- thin technical line art
- handwritten notes in illustrations
- code / nodes / flow diagrams

## Composition
- strong headline or primary task area
- lots of dark negative space
- a few intentional neon accents
- visual focus, not decoration everywhere

## Product-specific restraint
The LinkedIn carousel style is expressive.
The application should be approximately 50% less decorative.

Keep:
- palette
- hierarchy
- confidence
- technical + human tension

Reduce:
- glow
- large neon signage
- decorative stickers
- busy circuit backgrounds

## Image prompt seed
Use this only as a starting point:

"Dark premium engineering workspace, near-black navy background, subtle purple depth, neon pink accents, cinematic warm light, human-centered AI, handwritten engineering notes, restrained technical diagrams, sophisticated and approachable, no generic robot imagery, clean composition, premium product aesthetic."

## Don't
- blue-first SaaS design
- stock team photos
- humanoid AI robots
- hologram faces
- excessive glassmorphism
- gradients on every surface
- rainbow data visualizations
