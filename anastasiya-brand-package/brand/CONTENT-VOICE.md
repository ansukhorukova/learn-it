# Content Voice

## Personality
Intelligent. Warm. Practical. Self-aware. Curious.

## Writing principles
- use plain language
- say what happened, not what the feature "unlocks"
- prefer concrete verbs
- keep UI copy short
- explain complexity simply
- preserve the user's agency
- avoid judgmental language

## Product copy examples

### Buttons
Good:
- Create experiment
- Try again
- Compare results
- Save draft
- Review changes
- Continue

Avoid:
- Unlock insights
- Supercharge
- Revolutionize
- Experience magic

### Empty state
Good:
"No results yet. Run the first evaluation to see what changes."

Avoid:
"Your journey starts here! Unlock powerful AI-driven insights."

### Error
Good:
"We couldn't save this change. Your draft is still here."

Avoid:
"Oops! Something went wrong 😭"

### AI
Good:
"AI suggested this structure. Review it before applying."

Avoid:
"Let AI do the thinking for you."

## Core narrative
AI accelerates execution.
Human judgment defines value.

## Humor
Allowed in low-risk moments:
- build tools
- onboarding
- experiment dashboards
- developer workflows
- loading messages used sparingly

Do not use humor for:
- destructive actions
- billing
- security
- user loss / data loss
- serious errors
